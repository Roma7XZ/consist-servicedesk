# 🏢 Consist ServiceDesk

Современная корпоративная система управления инцидентами и ИТ-активами, разработанная для внутреннего использования. Проект автоматизирует процессы технической поддержки и учета импортозамещенного программного обеспечения.

## 🛠 Технологический стек

* **Frontend:** Vue.js 3, Vue Router, Pinia, Axios, Chart.js (модульная SPA архитектура).
* **Backend:** Node.js, Express, JWT-авторизация, bcryptjs.
* **Database:** PostgreSQL + Prisma ORM.
* **DevOps:** Docker, Docker Compose, Nginx.

## 🌟 Ключевой функционал

* **Ролевая модель доступа:** Изолированные права для Администраторов, Инженеров и Аналитиков.
* **Управление инцидентами (CRUD):** Создание заявок, назначение приоритетов, отслеживание статусов выполнения (Открыт, В работе, Решен, Закрыт).
* **Реестр ПО и Оборудования:** Учет корпоративных лицензий, импортозамещенного софта и инвентарных номеров техники.
* **Аналитический Дашборд:** Визуализация загруженности отдела и статистики обращений в режиме реального времени.
* **Защищенный API:** Все эндпоинты защищены JWT-токенами, настроен автоматический Axios-перехватчик для обработки истекших сессий.

## 🚀 Быстрый запуск (Docker)

Проект полностью контейнеризирован и готов к развертыванию на любой машине.

**1. Клонирование репозитория:**
\`\`\`bash
git clone https://github.com/ВАШ_ЛОГИН/consist-servicedesk.git
cd consist-servicedesk
\`\`\`

**2. Запуск контейнеров:**
\`\`\`bash
docker compose up -d --build
\`\`\`

**3. Инициализация базы данных и сидирование (выполняется в соседнем терминале после запуска):**
\`\`\`bash
# Применение миграций Prisma
docker exec -it consist-backend npx prisma db push

# Создание тестовых учетных записей (Admin, Engineer, Analyst)
docker exec -it consist-backend node prisma/seed.js
\`\`\`

**4. Доступ к приложению:**
* Клиентская часть: [http://localhost:5173](http://localhost:5173)
* API сервера: `http://localhost:3000/api`
